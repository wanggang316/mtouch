# References

External documentation, API references, and integration notes.

Keep LLM-friendly copies of external docs here so an agent can consult them
without network access. Prefer plain text or markdown.

## Index

- [mcp-swift-sdk.md](mcp-swift-sdk.md) — notes on the MCP Swift SDK used by
  `mtouch mcp` (transport, actor model, and the run-loop constraint that shapes
  how tool handlers hop to the main thread)

## Conventions

- Descriptive filenames: `<tool>-llms.txt` or `<service>-reference.md`
- Record the source URL and retrieval date at the top of each file
- Refresh as the external API evolves
